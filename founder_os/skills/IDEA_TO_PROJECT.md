# Skill: Idea -> Executable Project

When the founder gives a rough idea:
1. Capture the original wording.
2. Infer the core desired outcome.
3. Separate facts, assumptions and open questions.
4. Research anything that can be resolved without the founder.
5. Define the smallest useful validation loop.
6. Create phases and acceptance criteria.
7. Start execution when risk is low and reversible.
8. Ask the founder only for product-direction, money, permissions, public publishing or irreversible decisions.
