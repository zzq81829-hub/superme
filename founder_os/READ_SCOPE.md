# 读取权限边界 (Read Scope)

系统与所有 Worker（Codex / Claude / Antigravity / Grok / DeepSeek / Hermes）可以读取本机任意文件与目录，用于完成创始人指派的任务。除下述两类外，无需逐次询问创始人。

## 禁止读取：隐私 (Privacy)

- 密钥与凭据：API Key、Token、密码、私钥（`.ssh/`、`*.pem`、`*.key`、`.env` 中的密钥、`auth.json` 等）
- 浏览器历史、Cookie、登录态
- 私人聊天记录、私人通讯录、私人照片/视频
- 身份信息、医疗记录、个人简历（除非创始人明确要求处理该文件）

## 禁止读取：金额 (Money)

- 银行卡号、支付密码、支付凭证
- 账单、银行流水、账户余额明细
- 财务/税务文件（除非创始人明确要求处理该文件）

## 允许 (Allowed)

以上两类之外的一切内容：代码、项目文件、文档、图片、配置、日志、书摘等，均可直接读取。

## 铁律

- 这是「读取」授权：**不**包含删除、修改、发布、付费——这些仍走一级审批队列与成本守卫。
- 遇到无法判断是否属于隐私/金额的文件，**先停手询问创始人，不读**。
- 读到的隐私/金额内容不得写入任务报告、不得对外发布、不得复制留档。
