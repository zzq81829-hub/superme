# 书斋小红书图文排版模板

## 结论

`shuzhai-editorial-v1` 是书斋当前唯一默认图文模板。它把内容包转换为 4–7 页的 3:4 轮播版式计划，并把模板 ID 与收尾引导纳入冻结哈希。

## 版式规则

- 画布：1080 × 1440（3:4），四边安全区为上 88、右 76、下 112、左 76 px。
- 色彩：深墨黑 `#121212`、象牙白 `#F4EFE6`、高级红 `#A30F22`；只允许红色作为页码或重点，不作大面积渐变。
- 结构：封面 → 钩子 → 1–4 页洞察 → 收尾；不足时自动补一页留白页，始终保持至少 4 页。
- 密度：封面标题最多 3 行、每行 12 字；内页最多 64 字、6 行。超出的正文按自然句切分到后续页，最多 7 页，避免缩小字体硬塞。
- 收尾：默认“收藏这一页，留给下一次重读。”；可在 32 字内改写，并会进入审批哈希。

## 使用边界

模板仅生成本地的版式计划和预览信息，不调用图像服务、不生成外部发布请求。内容包仍须冻结、人工审批，并只能标记为 `ready_manual` 后由创始人线下手动发布。
