FOUNDER OS / 使用指南

从一个想法，到一份结果。

日常只需要交代结果、查看进度、做必要的决定。

打开公司

在桌面 superme 文件夹里双击 打开公司.cmd。它会检查服务，未启动时自动启动，然后打开独立工作窗口。重复打开会复用已有服务。

进入工作台 ↗

软件在本机运行；关闭工作窗口不会关闭后台服务，电脑关机后再次双击即可。工作数据保留在本机原有目录。

第一次交代工作

  1. 在“发起任务”输入你要的结果，如“把这份材料整理成三种选题，附上对应论据”。示例按钮只填入文字，不会自动执行。
  2. 首页提示默认工具未就绪时，点击 使用 Codex 或 使用 Grok Build。它只指定这次任务，不会放宽系统权限。
  3. 需要指定文件夹或验收标准时，展开“添加约束”。例如：存在: output/report.md。
  4. 点“开始推进”，或在输入框按 Ctrl + Enter。系统自动进入进度；高风险事项进入“待你决定”。

完整任务闭环

交代结果→ 风险检查→ 分配执行→ 机器验收→ 交付结果→ 反馈返工
  1. 提出需求：写明结果，需要时补充材料所在的项目路径。
  2. 系统检查：判断执行工具、可用容量和审批要求。等待与失败会在进度里明确显示。
  3. 执行与验收：执行工具处理任务，系统检查你指定的验收标准；不满足时按既有规则进行有限返工。
  4. 接收交付：在“看进度 → 已完成”里打开产物；电脑端可以直接打开文件位置。
  5. 继续完善：任务里的反馈入口可以记录问题，或提交反馈并返工。新的高风险操作仍要批准。
  6. 积累经验：反馈形成的记忆候选需要你确认，确认后才成为后续工作的依据。

账号与额度

侧栏“账号 / 容量”只管理两类执行工具：Antigravity 与 Codex；每类最多两个槽位（主力 A、备用 B）。页面显示的是脱敏状态，不显示密码、令牌或环境变量。

  1. Antigravity B：先在 Antigravity 官方软件里手动登录并切换到 B，再回到页面点“检查当前登录”。系统会把当前 CLI 登录视为唯一当前身份；检查通过后才允许它参与额度分配。
  2. Codex B：先添加 B，再绑定一个与 A 不同的独立配置目录，最后在该目录对应的 Codex 环境完成登录并检查。没有独立目录或没有验证时，B 会保持不可用。
  3. 额度分配：只有状态为“可用”的账号能接任务；遇到配额或限流会进入冷却并按规则尝试备用账号。登记了账号名称不等于额度已验证。
  4. 未来新增账号：超过 A/B 两个槽位会被拒绝，避免额度账本与真实登录身份失真。

本次已预留 Antigravity B 与 Codex B，二者都处于未登录/未验证状态；没有替你执行登录。

完整内容业务闭环

材料与选题→ 图文初稿→ 质检→ 冻结审阅→ 批准发布→ 真实数据→ 复盘与下一轮
  1. 从书籍或已有材料提取多个观点，按受众、痛点、事实依据选择值得做的题。
  2. 生成标题、正文和图文文件，进行事实、表达和视觉质量检查。
  3. 到“内容工作台”打开发布包，核对账号、图片、标题、正文。冻结后进入审批。
  4. 批准发布意味着授权对外发布。检查无误再操作。账号未就绪时等待登录或手动处理，不会伪装成已发布。
  5. 发布后补录或采集真实阅读、互动和关注数据；数据不可用时保留为未知。
  6. 根据结果判断哪一步需要改善，保存实验结论，并在下一轮选题中使用。连续完成多个真实周期，才能证明运营质量在提高。

本次软件验收不会替你批准任何已有发布包。真实发布和流量增长仍需要实际账号、有效数据和持续运营验证。

遇到问题怎么办

  • 连接中断：双击“打开公司.cmd”，然后点页面“重试连接”。页面会保留上次结果并明确提示离线。
  • 等待容量：打开任务详情查看原因；可选择已就绪工具重新派发，或等待工具恢复。
  • 提交失败：输入内容会保留，检查提示后重试。
  • Antigravity 受权限阻断：当前不默认放宽其权限；可选用其他已就绪执行工具。
  • 外部 Grok Bot：尚未验证回连，不应作为公司执行入口。本机工作台仍是主入口。
  • 手机：使用原有手机启动与配对流程；手机和电脑需要能互相访问。桌面地址 127.0.0.1 不能直接用于手机。
